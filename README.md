# Demo de reservas directas

Landing estática (HTML, CSS y JS) con un calendario por departamento y reserva por WhatsApp.

## Cómo usarla para un cliente nuevo
1. Duplica la carpeta.
2. Edita `config.js`: nombre, WhatsApp, pie de página y la lista de departamentos (nombre, personas, precio por noche).
3. Sube a GitHub Pages.

## Pendiente
- Las fechas ocupadas del demo son de ejemplo (función `busy` en `app.js`). Para el cliente real hay que leer el calendario iCal de Airbnb.
- Agregar fotos reales de cada departamento.
- Si el repo es público, no pongas ahí el WhatsApp ni los datos reales de clientes.
